# Шторка

Боковая панель рабочего стола для сайтов и мессенджеров.
Для Windows 10 22H2 / Windows 11 x64 (Intel/AMD).

## Установка

Скачайте [Shtorka-WebSetup.exe](https://github.com/id02041985-del/shtorka-releases/releases/latest/download/Shtorka-WebSetup.exe)
и нажмите «Установить». Нужен Интернет. Программа скачает последнюю версию,
проверит файл и установит Шторку для текущего пользователя.
Если WebView2 отсутствует, установщик загрузит необходимый компонент Microsoft.

Полный установщик также доступен в [Releases](https://github.com/id02041985-del/shtorka-releases/releases/latest).
В сервисы войдите самостоятельно; аккаунты в комплект не включены.
Новая установка начинается с пустой полоски: добавьте нужные сайты кнопкой «+».
При обновлении существующий список сайтов сохраняется.
Установщики пока не имеют собственной цифровой подписи издателя.

## Обновления

Меню значка Шторки в трее → «Проверить обновления».
Программа также проверяет версии в фоне не чаще раза в сутки после успешной
проверки и уведомляет о новом выпуске. Можно обновиться, отложить или пропустить
версию. В настройках можно отключить уведомления и автоматические проверки.
При обновлении программа перезапускается; настройки и входы сохраняются.
Скачивание происходит только после нажатия «Обновить».

## Данные и удаление

Настройки и входы хранятся локально в `%LOCALAPPDATA%\Shtorka`.
Проверка обновлений обращается к публичному GitHub Releases; данные сайтов,
переписки, пароли и настройки в эти запросы не включаются.
Удаление через «Приложения» Windows сохраняет папку данных; при необходимости
удалите её отдельно после закрытия Шторки. Общий WebView2 Runtime не удаляется.

Адаптивная раскладка WhatsApp зависит от текущей разметки сайта и может
потребовать обновления при изменениях со стороны WhatsApp.

Этот репозиторий предназначен для готовых выпусков. Публикация установщиков
не означает публикацию исходного кода или предоставление open-source лицензии.
